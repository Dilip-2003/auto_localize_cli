# AutoLocalize CLI Example

This directory demonstrates how `auto_localize_cli` is used in a Flutter project.

### CLI Usage

In your Flutter project terminal, run:

```bash
# 1. Initialize localization scaffolding
dart run auto_localize_cli:init

# 2. Extract strings and update source files
dart run auto_localize_cli:extract
```

For full documentation and workflow examples, see the [main README](../README.md).
